# Strategy Game Mobile

A lightweight mobile strategy game built with React Native and Expo.

## Features
- 5x5 tactical battlefield
- Build farms, towers, and bases
- Manage gold, food, and energy
- End-turn enemy AI
- Simple and beginner-friendly gameplay loop

## Getting started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the Expo app:
   ```bash
   npm start
   ```

3. Use Expo Go on your phone or run the Android/iOS simulator.

## Controls
- Tap a tile to build the currently selected structure.
- Use the action buttons to build a farm, tower, or base.
- Tap "Collect" to gather resources.
- Tap "End Turn" to trigger the enemy's attack and advance the round.

## Goal
Grow your territory, gather resources, and survive each enemy wave.
